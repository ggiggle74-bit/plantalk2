# CR-2S: 상태 기억 유효기간

## 목적

최근 사진 상태에 관한 질문은 최근 7일 안에 저장된 상태 확인 기록만 근거로 답한다. 오래되었거나 시각을 확인할 수 없는 DB 기록으로 현재 상태를 추측하지 않는다.

## 유효성 규칙

- 기준 시각은 `plant_memories.created_at`이다.
- 현재 시각부터 정확히 7일 전의 기록은 사용할 수 있다.
- 7일을 초과한 기록과 미래 시각의 기록은 사용할 수 없다.
- DB 기록에 `created_at`이 없거나 파싱할 수 없으면 사용할 수 없다.
- 사진 분석 직후 앱 내부에서 전달되는 시간 없는 상태 기억은 기존 즉시 응답 호환성을 위해 사용할 수 있다.

## 대화 처리

상태 기억 질문에 유효한 기록이 없으면 다음 의미의 로컬 안내로 종료한다.

> 우리 최근 일주일 동안은 상태를 같이 확인하지 않았네. 지금 사진으로 한번 봐줄래?

이 경우 DB 일반 대사, 일상 소재, Gemini, Kindwise를 호출하지 않는다. 사용자가 새 사진을 촬영하거나 선택하면 기존 카메라 분석 흐름이 새 상태 기억을 만든다.

## 경계

- 새 라우터나 대화 처리 슬롯을 추가하지 않는다.
- `PlantService`는 저장 기록을 읽은 직후 유효기간을 검사한다.
- `ChatPanelConversationController`도 요청에 직접 들어온 상태 기억을 같은 규칙으로 검사한다.
- `main.dart`, Supabase 스키마, Gemini 프롬프트, 카메라 분석 로직은 변경하지 않는다.
