# CR-2T: 상태 기억 화면 유효성

## 목적

대화 답변에 적용한 7일 상태 기억 규칙을 ChatPanel 화면에도 동일하게 적용한다. 만료된 기록을 상단의 "최근 상태 확인" 정보로 노출하지 않고, 만료된 초기값 때문에 더 최신 기록을 다시 읽지 못하는 상황을 막는다.

## 동작 규칙

- ChatPanel이 받은 초기 상태 기억은 보관하기 전에 `LatestConditionMemory.isFreshAt`으로 검사한다.
- 만료되었거나 미래 시각인 초기 기억은 없는 것으로 취급하고 최신 기록을 다시 읽는다.
- 비동기 로더가 반환한 기록도 상태에 저장하기 전에 같은 규칙으로 검사한다.
- 화면을 다시 그리는 시점에도 같은 규칙을 적용해 유효기간을 지난 문구를 표시하지 않는다.
- 사진 분석 직후 전달되는 시간 없는 인메모리 결과는 CR-2S의 호환성 규칙에 따라 계속 표시한다.

## 경계

- 유효기간의 기준과 계산은 계속 `LatestConditionMemory`가 소유한다.
- 대화 라우터, controller, 카메라 분석, Supabase 스키마, Gemini, Kindwise는 변경하지 않는다.
- 새 대화 처리 슬롯이나 외부 호출을 추가하지 않는다.
